# Security Policy

## Supported Versions

Only the latest release is supported. Please update to the newest version
from the [Releases page](https://github.com/cursorblinkrate-boop/bger-reader-addon/releases)
before reporting a problem.

## Reporting a Vulnerability

If you find a security problem, please report it privately:

1. Preferred: use GitHub's private reporting form under
   **Security → Report a vulnerability** in this repository.
2. If GitHub is not reachable: send an e-mail to **bge.reader@gmail.com**.

Please do not open a public issue for security problems.

This is a small, single-person project. You will usually get a reply
within a few days. Confirmed problems are fixed in the next release.
