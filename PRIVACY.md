# Privacy Policy

accessibility add-on for bger.ch and bvger.ch – browser extension for decisions of the Swiss Federal Supreme Court and the Swiss Federal Administrative Court. Last updated: 2026-09-26

1. The add-on does not collect, store or transmit any personal data. There are no user accounts, no registration, no advertising, no usage statistics and no crash reports.
2. It runs entirely inside your browser. It opens no connection to any server, downloads nothing and sends nothing – not even to the developer.
3. It only runs on `search.bger.ch`, `relevancy.bger.ch` and `bvger.weblaw.ch`, and there it changes only how the decision is displayed (font, spacing, colours, folded citations). It does not read page content, keeps no list of decisions you have read and does not query browser or system settings.
4. The only thing it stores are the display settings you choose yourself (font, font size, spacing, colour scheme, interface language), locally in the browser's extension storage (`storage.local`). This storage is not synchronised with any account and is deleted by the browser when the add-on is removed.
5. The add-on's only permission is `storage` (local storage for the settings).
6. When you download the add-on from a store (Google Chrome Web Store, Mozilla Add-ons, Microsoft Edge Add-ons), the store operator collects its own data under its own privacy policy; the add-on has no influence on that.
7. Private project, not affiliated with the Swiss Federal Supreme Court, the Federal Administrative Court or Weblaw. Source code: https://github.com/cursorblinkrate-boop/bger-reader-addon
8. Privacy questions: bge.reader@gmail.com
