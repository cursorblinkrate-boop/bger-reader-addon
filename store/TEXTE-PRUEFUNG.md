# Texte zur Prüfung – Deutsch / English

Alle Texte, die Nutzerinnen und Nutzer ohne Programmierkenntnisse zu sehen bekommen: Store-Einträge, die Kurztexte im Paket (Erweiterungsverwaltung des Browsers, Symbolleiste), die Angaben in den Datenschutz-Formularen der Stores, die Datenschutzerklärung, das README und die Release-Notiz. Entwurf, Stand 2026-09-26, zur Bearbeitung durch die Autorin.

**So geht's:** Text direkt in der Spalte ändern (Obsidian-Tabelle oder ein Texteditor; Zeilenumbruch in einer Zelle ist `<br>`). Danach die Datei zurückgeben – Commit auf GitHub oder als Datei in den Chat. Die nächste Session überträgt die Änderungen in die Quelldateien (Spalte „Quelle" je Abschnitt) und zieht Französisch und Italienisch nach. Die Texte der Bedienoberfläche (Panel, Fenster) stehen nicht hier, sondern in `SPRACHEN.md`.

**Feste Grenzen der Stores (nicht verhandelbar):** Name höchstens 45 Zeichen und beginnt mit „BGer Reader"; Kurzbeschreibung höchstens 132 Zeichen; Beschreibung mindestens 250 Zeichen (Edge); keine Wiederholung eines Suchbegriffs mehr als fünfmal, keine Aufzählungen von Suchbegriffen, keine Vergleiche mit anderen Erweiterungen, keine Superlative („Nr. 1", „beste"), keine Heilversprechen (nur „Schriften, die für Menschen mit Legasthenie bzw. Sehbeeinträchtigung entworfen wurden"). Alles in den Store-Formularen muss der Code belegen.
